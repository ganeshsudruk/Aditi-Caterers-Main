# 1. Objective

The objective of this document is to establish a consistent brand identity and visual design system for the Aditi Caterers website and Admin Panel.

All designers and developers must follow these guidelines while developing website pages, reusable components, forms, cards, buttons, navigation elements, and other UI sections.

The final design must represent a professional catering business and create trust among customers.

# 2. Brand Identity

## 2.1 Business Information

| Field | Details |
|---|---|
| Brand Name | Aditi Caterers |
| Business Category | Catering Services |
| Business Type | Event Catering |
| Target Audience | Individuals, Families, Organizations |
| Service Coverage | Villages and Cities |
| Website Languages | English and Marathi |
| Primary Website Goal | Generate Customer Enquiries and Bookings |

## 2.2 Brand Personality

The brand should communicate:

- Trustworthy.
- Professional.
- Traditional.
- Premium.
- Welcoming.
- Reliable.
- Quality-focused.
- Customer-friendly.

The overall design should combine traditional Indian catering aesthetics with a clean and modern website experience.

# 3. Brand Logo Guidelines

The official Aditi Caterers logo must be used throughout the application.

## 3.1 Logo Requirements

- Use the original business logo.
- Do not redesign the logo without approval.
- Do not change the original logo colors.
- Do not stretch or distort the logo.
- Maintain the original aspect ratio.
- Maintain sufficient spacing around the logo.
- Use a transparent PNG or SVG wherever available.
- Ensure the logo is visible on both desktop and mobile screens.

## 3.2 Logo Variations

If the business provides multiple logo formats, use them appropriately:

| Logo Type | Usage |
|---|---|
| Primary Logo | Main website navbar |
| Light Logo | Dark background sections |
| Dark Logo | Light background sections |
| Icon Logo | Favicon and compact mobile usage |

## 3.3 Logo Placement

- Navbar: Left side.
- Footer: Brand information section.
- Admin Login: Above login form.
- Admin Sidebar: Top branding section.
- Browser: Favicon.

## 3.4 Logo Restrictions

Do not:

- Add unnecessary effects.
- Change logo proportions.
- Apply random colors.
- Add shadows unless approved.
- Use low-resolution logo files.
- Use unrelated stock logos.

**Pending Asset:** Original Aditi Caterers logo must be collected from the business owner before final implementation.

# 4. Brand Color Guidelines

The website should use a professional color palette that matches the catering business identity.

## 4.1 Recommended Primary Colors

| Color Name | Hex Code | Usage |
|---|---|---|
| Maroon | #641E2B | Primary brand color |
| Gold | #C9A45C | Accent and highlights |
| White | #FFFFFF | Main background |
| Light Cream | #FAF7F2 | Section background |

| Medium Gray | #6C757D | Secondary text |
| Light Gray | #F1F1F1 | Borders and surfaces |

These are proposed colors and must be checked against the official logo before final approval.

## 4.2 Primary Color Usage

**Maroon:**

- Primary buttons.
- Navbar branding.
- Important headings.
- Active navigation links.
- Primary action elements.

**Gold:**

- Decorative highlights.
- Small borders.
- Section accents.
- Premium visual elements.
- Selected icons.

**White:**

- Cards.
- Forms.
- Main content backgrounds.
- Navigation backgrounds where applicable.

**Light Cream:**

- Hero backgrounds.
- Alternate content sections.
- Special promotional sections.

## 4.3 Color Usage Rules

- Maintain consistent color usage.
- Avoid introducing unnecessary colors.
- Do not use too many gradients.
- Avoid excessive bright colors.
- Maintain sufficient text contrast.
- Use approved colors for buttons and interactive states.

# 5. Typography Guidelines

Typography must support both English and Marathi content.

## 5.1 English Font

Recommended font:

- Poppins.

Usage:

- Headings.
- Navigation.
- Buttons.
- Body text.

## 5.2 Marathi Font

Recommended font:

- Noto Sans Devanagari.

Usage:

- Marathi headings.
- Navigation labels.
- Paragraphs.
- Forms.
- Buttons.
- Admin Panel content.

## 5.3 Typography Rules

- Maintain consistent heading hierarchy.
- Avoid unnecessarily large text.
- Use readable font sizes.
- Maintain sufficient line height.
- Avoid decorative fonts for paragraphs.
- Marathi text must not be clipped or overlap.
- Test Marathi rendering on mobile devices.

## 5.4 Suggested Font Sizes

| Element | Desktop | Mobile |
|---|---:|---:|
| Main Heading | 36–48px | 28–34px |
| Section Heading | 28–32px | 23–28px |
| Card Heading | 20–24px | 18–21px |
| Body Text | 16px | 15–16px |
| Small Text | 13–14px | 12–13px |
| Button Text | 15–16px | 14–16px |

These values are guidelines. Adjust based on actual layout and Marathi text length.

# 6. Image & Photography Guidelines

Real business photographs should be preferred over generic stock images.

## 6.1 Required Image Categories

- Wedding Catering.
- Birthday Events.
- Engagement Events.
- Reception Events.
- Food Preparation.
- Maharashtrian Food.
- Punjabi Food.
- South Indian Food.
- Buffet Arrangements.
- Catering Staff.
- Event Decorations.
- Food Presentation.

## 6.2 Image Quality

- Use high-quality photographs.
- Maintain consistent image presentation.
- Avoid blurry photographs.
- Avoid stretched images.
- Use appropriate aspect ratios.
- Optimize images before uploading.
- Use descriptive image alt text.

## 6.3 Image Behaviour

- Use `object-fit: cover` for card images where suitable.
- Use `object-fit: contain` for logos.
- Use lazy loading for below-the-fold images.
- Provide a fallback for unavailable images.
- Maintain responsive image dimensions.

## 6.4 Image Restrictions

- Do not use copyrighted images without permission.
- Do not use unrelated catering photographs.
- Do not use watermarked images.
- Do not publish customer photographs without appropriate permission.

# 8. Button Design Guidelines

All buttons must follow a consistent design system.

## 8.1 Primary Button

Usage:

- Book Now.
- Submit Booking.
- Contact Us.
- Send Enquiry.

Style:

- Maroon background.
- White text.
- Consistent padding.
- Moderate border radius.
- Clear hover and focus states.

## 8.2 Secondary Button

Usage:

- Learn More.
- View Gallery.
- Explore Menu.
- View Details.

Style:

- White or transparent background.
- Maroon border.
- Maroon text.

## 8.3 Button Requirements

- Maintain consistent heights.
- Use readable labels.
- Provide hover states.
- Provide keyboard focus indicators.
- Prevent multiple submissions where applicable.
- Show loading state during API operations.
- Ensure touch-friendly mobile dimensions.

# 9. Card Design Guidelines

Reusable cards must be used wherever suitable.

Examples:

- Service Cards.
- Food Item Cards.
- Package Cards.
- Gallery Cards.
- Testimonial Cards.
- Award Cards.

Requirements:

- Consistent spacing.
- Clean background.
- Proper image proportions.
- Clear headings.
- Readable descriptions.
- Consistent border radius.
- Minimal shadows.
- Responsive layout.

Avoid unnecessary decoration and excessive card nesting.

# 10. Form Design Guidelines

All public and admin forms must follow a consistent style.

Requirements:

- Clear field labels.
- Proper input types.
- Helpful placeholders.
- Required field indicators.
- Inline validation messages.
- Readable error messages.
- Proper focus states.
- Consistent input heights.
- Responsive form layouts.
- Marathi and English validation messages.

Forms must remain usable on mobile screens.

# 11. English & Marathi Design Guidelines

The website must support English and Marathi without breaking the visual layout.

Requirements:

1. Both languages must use the same design system.
2. Text containers must support different content lengths.
3. Buttons must adapt to Marathi text.
4. Navigation must not overflow.
5. Cards must maintain consistent alignment.
6. Forms must support Marathi labels and validation.
7. Headings must wrap naturally.
8. Do not hardcode fixed widths that clip Marathi content.
9. Set the correct document language.
10. Use the approved fonts for each language.

Example:

| English | Marathi |
|---|---|
| Home | मुख्यपृष्ठ |
| About Us | आमच्याबद्दल |
| Our Services | आमच्या सेवा |
| Food Menu | खाद्यपदार्थ मेनू |
| Gallery | फोटो गॅलरी |
| Book Now | बुकिंग करा |
| Contact Us | संपर्क साधा |

# 12. Layout & Spacing Guidelines

- Use Bootstrap container and grid systems.
- Maintain consistent section spacing.
- Avoid unnecessary large margins.
- Use reusable spacing utilities.
- Maintain proper alignment.
- Keep content within readable widths.
- Ensure consistent spacing between headings, descriptions, and buttons.

Suggested Bootstrap breakpoints:

| Device | Bootstrap Breakpoint |
|---|---|
| Extra Small | Below 576px |
| Small | 576px and above |
| Medium | 768px and above |
| Large | 992px and above |
| Extra Large | 1200px and above |
| Extra Extra Large | 1400px and above |

Minimum supported viewport: 320px.

# 13. Animation & Interaction Guidelines

Use subtle animations only when they improve usability.

Allowed:

- Button hover transitions.
- Dropdown transitions.
- Image hover effects.
- Light scroll animations.
- Modal transitions.

Avoid:

- Excessive animations.
- Flashing elements.
- Unnecessary moving backgrounds.
- Heavy animation libraries for simple effects.

Respect reduced-motion preferences where applicable.

# 14. Admin Panel Design Guidelines

The Admin Panel must follow the same brand identity as the public website.

Requirements:

- Consistent Maroon and Gold branding.
- Clean dashboard layout.
- Professional sidebar.
- Consistent top navigation.
- Reusable tables and cards.
- Readable forms.
- Clear status indicators.
- Responsive design.
- English and Marathi support.

The Admin Panel should prioritize usability and information clarity over decorative design.

# 15. Accessibility Guidelines

- Use semantic HTML.
- Provide accessible form labels.
- Maintain sufficient color contrast.
- Support keyboard navigation.
- Show visible focus indicators.
- Add alt text to meaningful images.
- Use accessible button names.
- Avoid color-only status indicators.
- Support screen readers.
- Ensure Marathi text is accessible and readable.

4. Avoid unnecessary custom CSS.
5. Use reusable design components.
