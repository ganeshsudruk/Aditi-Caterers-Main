# 1. प्रोजेक्टची ओळख

अदिती केटरर्स हा विविध प्रकारच्या कार्यक्रमांसाठी केटरिंग सेवा पुरवणारा व्यवसाय आहे.

या प्रोजेक्टचा मुख्य उद्देश अदिती केटरर्ससाठी एक आधुनिक, आकर्षक, व्यावसायिक आणि वापरण्यास सोपी Website तयार करणे हा आहे.

या Website च्या माध्यमातून ग्राहकांना घरबसल्या केटरिंग सेवा, खाद्यपदार्थांचे मेनू, पॅकेजेस, कार्यक्रमांचे फोटो आणि इतर माहिती पाहता येईल. तसेच ग्राहक Website वरून थेट कार्यक्रमासाठी बुकिंग किंवा चौकशी करू शकतील.

या प्रोजेक्टमध्ये Website सोबत एक स्वतंत्र Admin Panel देखील तयार करण्यात येणार आहे. त्याद्वारे व्यवसायाचे मालक किंवा अधिकृत कर्मचारी Website वरील माहिती, बुकिंग, ग्राहक, खाद्यपदार्थ, पॅकेजेस आणि इतर गोष्टी व्यवस्थापित करू शकतील.

संपूर्ण Website इंग्रजी आणि मराठी या दोन्ही भाषांमध्ये उपलब्ध असेल.

# 6. मराठी आणि इंग्रजी भाषेची सुविधा

संपूर्ण Website आणि Admin Panel मध्ये मराठी व इंग्रजी या दोन भाषांचा पर्याय असेल.

### आवश्यक सुविधा

1. Website उघडल्यानंतर Default भाषा इंग्रजी असेल.
2. ग्राहकांना मराठी किंवा इंग्रजी भाषा निवडता येईल.
3. भाषा बदलल्यावर संपूर्ण Website वरील मजकूर बदलेल.
4. भाषा बदलल्यानंतर ग्राहक त्याच Page वर राहतील.
5. निवडलेली भाषा Refresh केल्यानंतरही कायम राहील.
6. Navbar, Buttons, Forms, Messages आणि Footer या सर्व ठिकाणी भाषेची सुविधा असेल.
7. Admin Panel मध्ये देखील दोन्ही भाषांचा पर्याय असेल.
8. मराठी अक्षरे सर्व Devices वर व्यवस्थित दिसली पाहिजेत.
9. एखाद्या माहितीचे मराठी भाषांतर उपलब्ध नसेल तर इंग्रजी माहिती दाखवली जाईल.
